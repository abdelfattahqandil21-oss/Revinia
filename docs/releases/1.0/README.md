# Rivinia 1.0 release records

This folder preserves the 1.0 release-candidate program's API review, human checks, merge log, publish runbook, release order, and package README template. The records contain time-specific package versions, tags, registry state, and verification results. They are historical evidence, not a current publish procedure; refresh all external state and gates before reuse.

- [`API-SURFACE.md`](API-SURFACE.md) — reviewed public names and defaults.
- [`HUMAN-CHECKS.md`](HUMAN-CHECKS.md) — checks requiring a person or real device.
- [`MERGES.md`](MERGES.md) — historical integration evidence.
- [`PUBLISH-RUNBOOK.md`](PUBLISH-RUNBOOK.md) — dated release procedure and outcomes.
- [`RELEASE.md`](RELEASE.md) — historical release order and state.
- [`README-TEMPLATE.md`](README-TEMPLATE.md) — S9 package README structure used by the release checks.
- [`STABLE-1.0.0.md`](STABLE-1.0.0.md) — current eleven-package stable release preparation and open gates.

Current versioning policy lives in [`../../engineering/VERSIONING.md`](../../engineering/VERSIONING.md); immutable source and documentation snapshots are the exact package tags.

# Rivinia 1.1 release

The planned 1.1 release is the first synchronized release of all five members
of `rivinia-1.0`, including `@rivinia/popup`. The release version is planned as
`1.1.0`; the dist-tag strategy is still an owner decision. This is not an
authorization to bump, merge, tag or publish.

- [Publish runbook](PUBLISH-RUNBOOK.md) — verified package order, gates,
  registry checks, approval template and rollback procedure.
- [1.0 human checks](../1.0/HUMAN-CHECKS.md) — outstanding manual checks to
  carry into the 1.1 release review.
- [Versioning policy](../../engineering/VERSIONING.md) — synchronized group
  and compatibility rules.

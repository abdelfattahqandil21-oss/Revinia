# Install

Install the package and configure its Angular integration.

[Back to @rivinia/datepicker README](https://github.com/abdelfattahqandil21-oss/Rivinia/blob/datepicker/v1.0.1/projects/datepicker/README.md)

## Install

```bash
npm install @rivinia/datepicker
```

or

```bash
pnpm add @rivinia/datepicker
```

or

```bash
yarn add @rivinia/datepicker
```

or

```bash
bun add @rivinia/datepicker
```

The optional theme layer, if you want the shared token set:

```bash
npm install @rivinia/theme
```

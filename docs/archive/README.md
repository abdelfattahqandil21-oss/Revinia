# Historical archive

Files in this directory are dated evidence snapshots: audits, proofs,
verification results, and completed task reports. They describe the source,
tools, and results available at their stated date or commit. They are not
current policy or release instructions.

For current repository rules, use [the engineering index](../engineering/README.md),
[the decision log](../DECISIONS.md), and [the documentation map](../README.md).
The [repository architecture archive index](../repository-architecture/README.md) contains the
reports moved from the former `docs/repository-architecture/` collection.

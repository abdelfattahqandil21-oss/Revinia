# Install

Install the package and configure its Angular integration.

[Back to @rivinia/table README](https://github.com/abdelfattahqandil21-oss/Rivinia/blob/table/v1.0.1/projects/table/README.md)

## Install

```bash
npm install @rivinia/table
```

or

```bash
pnpm add @rivinia/table
```

or

```bash
yarn add @rivinia/table
```

or

```bash
bun add @rivinia/table
```

# Security policy

Please report suspected vulnerabilities privately through GitHub's **Private vulnerability reporting** feature for this repository. Open the repository's **Security** tab and choose the private reporting option; do not post exploitable details in a public issue.

Please include the affected package or repository path, impact, and steps to reproduce. Maintainers can investigate and coordinate a fix before public disclosure.

Supported versions and response expectations will be documented here when the maintainers establish them.

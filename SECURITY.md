# Security policy

Please report suspected vulnerabilities privately through [GitHub's Private vulnerability reporting for this repository](https://github.com/abdelfattahqandil21-oss/Rivinia/security). Choose **Report a vulnerability**; do not post exploitable details in a public issue.

Please include the affected package or repository path, impact, and steps to reproduce. Maintainers can investigate and coordinate a fix before public disclosure.

Supported versions and response expectations will be documented here when the maintainers establish them.
